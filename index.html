좋은 오픈소스, 더 쉽게.

OpenAppShelf는 개발 지식이 없어도 쓸 수 있는 오픈소스 앱을 발견하고 설치하도록 돕는 카탈로그입니다.

어떤 앱을 담나요?

소스가 공개되어 있고, 일반 사용자가 사용할 수 있는 앱을 직접 선별합니다. 앱 설명과 공식 배포 파일, 준비 조건을 함께 정리합니다.

파일은 어디에서 받나요?

각 프로젝트의 공식 GitHub 릴리스에서 받습니다. OpenAppShelf는 설치 파일을 보관하거나 자동으로 실행하지 않습니다. 운영체제와 파일 종류를 확인한 뒤 다운로드하세요.

정보는 언제 확인했나요?

앱별 정보 확인일은 상세 화면에 표시합니다. 자동으로 갱신되지 않으며, 새 버전과 자세한 지원 조건은 각 앱의 공식 안내에서 확인할 수 있습니다. 이 카탈로그에 소개된 앱의 설치·실행을 모두 시험한 것은 아닙니다.

함께 만드는 카탈로그

OpenAppShelf는 함께 만드는 오픈소스 프로젝트입니다. GitHub 저장소에서 앱을 제안하거나 기여할 수 있습니다. 앱 이미지와 상표의 권리는 각 제작자에게 있습니다.
